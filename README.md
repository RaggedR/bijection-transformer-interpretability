# Bijection-Transformer Interpretability

Interpretability research on transformers that learn **combinatorial bijections** —
inverse RSK, growth diagrams, cylindric RSK — and what their internal features
actually represent.

- **`rsk/`** — "Learning Combinatorial Bijections with Transformers: Inverse RSK,
  Growth Diagrams, and Interpretable Features." Model, training, ablations, paper.
- **`sae/`** — "Testing Compositional Faithfulness: Causal Interventions on Sparse
  Autoencoder Features in a Combinatorial Bijection Transformer."
- **`warnaar/`** — numerical verification of Warnaar's conjecture 2.7.

Model checkpoints and activation tensors (several GB) are **not** committed — they
are regenerable from the training code.
